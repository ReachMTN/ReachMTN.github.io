# ReachMTN Portfolio — Personal Update

This package updates the Education page with:
- User-provided graduation photo (`graduation-photo.jpeg`)
- PL-300 Power BI Data Analyst Associate shown as In Progress
- AWS Cloud Practitioner shown as Completed
- A personal “Beyond the Data” section about travel, culture, strategy games, and adaptability

It retains the interactive `dashboard.html` page and the rest of the portfolio files.

To publish, upload all files in this ZIP to the root of `ReachMTN/ReachMTN.github.io`, replace same-named files, and commit changes. Keep `graduation-photo.jpeg` beside `education.html` so the image loads.

The dashboard uses synthetic demonstration data.
