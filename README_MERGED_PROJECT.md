# ReachMTN Portfolio — Merged Analytics Project

This website package combines the iPhone Checkout Analytics Dashboard and Sales Performance & Inventory Analysis into one featured portfolio project.

## Featured project
**Checkout, Sales Performance & Inventory Analytics**
- Interactive dashboard mockup for spend, checkout count, savings, failures, trends, and product comparisons.
- SQL Server starter script for data organization, aggregation, and quality checks.
- Power BI build guide with suggested DAX measures and report layout.
- Synthetic sample CSV for demonstration only.

## Publish
Upload all files in this ZIP into the root of `ReachMTN/ReachMTN.github.io`, replacing files with the same names, and commit the changes. Ensure `dashboard_mockup.html`, `checkout_analytics.sql`, `powerbi_build_guide.md`, and `checkout_transactions_sample.csv` are in the same root folder as `projects.html`.

## Data note
The supplied CSV is synthetic demonstration data, not real purchase or inventory history. The dashboard does not connect to a live purchasing or inventory database.
